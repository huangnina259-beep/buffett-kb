# Invited English beta

This service runs the English Q&A selected in local testing. The hosting start command reads the same checked-in model configuration and requires two private runtime variables, `AI_API_KEY` (MarsAPI) and `ENGLISH_BETA_PASSWORD` (a random invitation password, at least 16 characters). The browser prompts once for username `reader` and the shared password. Use the public host's HTTPS address. Questions and optional feedback are stored on the service volume.

Create the release directory from the committed revision with `python scripts/package_english_beta.py ../buffett-english-upload`. The package includes only the English runtime and its two source files. Mount a service volume at `/app/database`. Use one instance. Upload that directory to the dedicated service using `railway up ../buffett-english-upload --path-as-root --project PROJECT --environment ENVIRONMENT --service SERVICE`. Generate a service domain in Railway and wait for `/health` to report readiness. The volume survives ordinary restarts and retains the index, questions, feedback and provider-call ledger. Initial indexing uses two embedding requests. A compatible volume is reused on restart.

The default cumulative allocation is 150 provider attempts, including the embedding calls. A completed answer normally uses three attempts. This covers a pilot of 20–30 questions plus end-to-end checks. Hosting charges depend on plan and actual usage. Keep secrets in hosting variables. Transfer the invitation password to readers separately from the application URL.

Before sharing the address, use a fresh browser or the smoke client to ask a new question, open a cited source and submit a follow-up. Also test the feedback controls on a completed reply. From the service runtime, `python scripts/review_english_pilot.py --since YYYY-MM-DD --limit 30` shows recent browser submissions, sources, initial and final latency, feedback, and reported Stop or page-leave events. Missing events and feedback are unknown. The operator can review these records privately.
